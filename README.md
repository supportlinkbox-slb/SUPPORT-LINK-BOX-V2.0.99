# Support Link Box (v2.1.0 Enterprise Edition)

Mutual Engagement System & Facebook Creator Support Network.

## Features
- **Daily Links Sequencing**: Strict row-lock serial assignment (01, 02...).
- **All Done Engine**: 5:00 PM BDT unlock with top 5 fastest supporter bonus tiers.
- **Movie Lover (3-Layer Auth)**: Secure access token validation with zero leakage.
- **Admin Dashboard & Settings**: Live operational controls, timers & power toggles.
- **Master A to Z SQL**: Full database migration scripts included in `/supabase/FULL_A_TO_Z_DATABASE_MIGRATION.sql`.

## Deploying to GitHub Pages
This repository is configured with GitHub Actions workflow at `.github/workflows/deploy.yml` and `base: './'` in `vite.config.ts`.
